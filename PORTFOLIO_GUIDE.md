# 🚀 Pranshul Chopra — Product Management Portfolio

This portfolio is custom-engineered to showcase **Product Management (PM)** and **Product Solutions/Strategy (PS)** competencies, highlighting product discovery, ruthless scoping, systems architecture, and engineering trade-offs.

---

## 🛠️ Stack & Architecture
- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (Navy `#0a0f1a`, Sky Blue `#87ceeb`, Royal Gold `#d4a843`)
- **Typography:** Cinzel (Serif), Inter (Sans), IBM Plex Mono (Monospace)
- **Motion & Physics:** Framer Motion
- **Icons:** Lucide React

---

## 🌟 Key Sections Tailored for PM & PS Hiring
1. **Hero & PM Metrics:** Direct positioning (*"Product builder with systems intuition and technical fluency"*) with key metrics (4-month lifecycle, 105/105 release tests passed, ~400MB RAM regression fixed, 0ms local latency).
2. **PM Primitives Marquee:** Dual-row infinite ticker of PM competencies (*PRDs/FRDs, P0–P4 Backlog Scoping, User Mental Models, Threat Modeling, Context Engineering*).
3. **Product Philosophy:** 4 core convictions on product diagnosis, scope pruning, distribution reliability, and local-first sovereignty.
4. **Featured Case Studies:**
   - **PranshulOS:** End-to-end product ownership, mental model separation (routines vs tasks), pywebview $\rightarrow$ Electron migration, and v2.0 AI scope cut $\rightarrow$ v2.4 Chibi Plan Mode.
   - **FLUIDCB:** AI product architecture, multi-tier memory decay, and cost optimization via deterministic fallbacks.
   - **Context Integrity Framework (CIF):** Research paper draft proposing a 4-pillar evaluation methodology (constraint persistence, decision stability, goal coherence, token efficiency).
5. **Product Decision Log:** Structured documentation of alternatives considered, chosen paths, PM rationales, and measured outcomes.
6. **Skills & Systems Toolkit:** Categorized into Product Direction, Product Practice/Documentation, and Technical Fluency.
7. **Contact Channels:** Direct mail, LinkedIn, GitHub, and Adobe CV links.

## ⚡ Running & Deploying

### 1. Run Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 2. Build for Production
```bash
npm run build
```

### 3. Deploy to Vercel
Import the repository on [Vercel](https://vercel.com) — Next.js will be auto-detected and deployed instantly.
